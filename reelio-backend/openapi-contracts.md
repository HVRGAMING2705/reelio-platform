# API Contracts (JSON)\n\nBase: `/api`\n\n## Auth\n\n### POST /api/auth/register\nRequest:\n```json\n{\"name\":\"Jane\",\"email\":\"jane@example.com\",\"password\":\"password123\"}\n```\nResponse 201:\n```json\n{\"user\":{\"id\":\"uuid\",\"name\":\"Jane\",\"email\":\"jane@example.com\",\"role\":\"client\",\"created_at\":\"2026-01-01T00:00:00Z\"}}\n```\nErrors:\n- 400 `{ \"error\": \"invalid input\" }`\n- 409 `{ \"error\": \"email already registered\" }`\n\n### POST /api/auth/login\nRequest:\n```json\n{\"email\":\"jane@example.com\",\"password\":\"password123\"}\n```\nResponse 200:\n```json\n{\"user\":{\"id\":\"uuid\",\"name\":\"Jane\",\"email\":\"jane@example.com\",\"role\":\"client\",\"created_at\":\"...\"}}\n```\nErrors:\n- 401 `{ \"error\": \"invalid credentials\" }`\n\n### GET /api/auth/me\nResponse 200:\n```json\n{\"user\":{\"id\":\"uuid\",\"name\":\"Jane\",\"email\":\"jane@example.com\",\"role\":\"client\",\"created_at\":\"...\"}}\n```\nErrors:\n- 401 `{ \"error\": \"unauthorized\" }`\n\n### POST /api/auth/logout\nResponse 200:\n```json\n{\"ok\":true}\n```\n\n## Projects\n\n### POST /api/projects (auth)\nRequest:\n```json\n{\"title\":\"New Project\",\"description\":\"Details\",\"status\":\"pending\",\"user_id\":\"uuid\",\"created_at\":\"...\"}}\n```\n\n### GET /api/projects (auth)\nResponse 200:\n```json\n{\"projects\":[{\"id\":\"uuid\",\"title\":\"...\",\"description\":\"...\",\"status\":\"pending\",\"user_id\":\"uuid\",\"created_at\":\"...\"}]}\n```\n\n### GET /api/projects/:id \"error\": \"forbidden\" }` (client accessing others)\n\n### GET /api/admin/projects (admin)\nResponse 200:\n```json\n{\"projects\":[...]}\n```\n\n### PATCH /api/projects/:id (admin)\nRequest:\n```json\n{\"title\":\"Updated\",\"description\":\"Updated\",\"status\":\"in_progress\",\"user_id\":\"uuid\"}\n```\nResponse 200:\n```json\n{\"project\":{...}}\n```\n\n### DELETE /api/projects/:id (admin)\nResponse 200:\n```json\n{\"ok\":true}\n```\n\n## Portfolio\n\n### GET /api/portfolio\nResponse
